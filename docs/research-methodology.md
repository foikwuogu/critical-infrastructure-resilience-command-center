# Research Methodology

The command center treats resilience as a multidimensional problem.

Dimensions:
- cyber trust
- cryptographic readiness
- physical asset health
- operational availability

The prototype computes an illustrative resilience score from these dimensions.

Scenarios test how resilience changes when:
- cyber trust is reduced
- legacy cryptography becomes a migration priority
- equipment degradation increases
- cyber and physical risks occur simultaneously

The score is a research-model construct, not a standardized industry metric. For publication, weights must be justified, sensitivity-tested and validated against an appropriate reference dataset.
